591 vs i智慧 自動比對工具

一次安裝，之後每天點一下就自動比對廣告與關注物件

📋 工具能做什麼

  1. 自動抓取你 i智慧 的「關注物件」清單（社區+總價）
  2. 自動抓取你 591 會員中心 的「開啟中物件」清單（社區+總價）
  3. 比對兩邊，列出：價格不一致、591 多出的廣告（要下架）、關注沒對應 的物件
  4. 整個過程約 10–20 秒，會在新分頁顯示結果

1 安裝擴充功能（每台電腦只做一次）

  1. 打開 Chrome 瀏覽器，在網址列貼上：
    （這是 Chrome 內建的擴充功能管理頁，貼上後按 Enter）
  2. 右上角有一個「開發人員模式」開關，把它打開（藍色亮起）
  3. 左上角會出現「載入未封裝項目」按鈕，點它
  4. 選擇這個資料夾：
    D:\桌面快捷\自動對比廣告工具
    （就是這個說明檔所在的整個資料夾）
  5. 看到「591 廣告 vs i智慧 自動比對工具」出現在清單上 = 成功
  6. 右上角拼圖圖示 🧩 → 找到這個擴充功能 → 點「📌」釘選到工具列
✅ 完成！Chrome 右上角會看到一個橘色「591」按鈕

2 每天怎麼使用

  1. 先確認你已經在 Chrome 登入：
    🏠 i智慧：https://is.ycut.com.tw/ + 🏘️ 591 會員中心：https://user.591.com.tw/
    （平常你怎麼登入就怎麼登入，工具會用你的登入身分去抓資料）
  2. 點 Chrome 右上角橘色「591」按鈕
  3. 按「🔍 開始自動比對」
  4. 新分頁打開後，等 10–20 秒就會看到比對結果
⚠ 注意：工具會在背景開啟分頁去抓資料，過程中分頁會閃過一下是正常的

3 結果怎麼看

顏色意思動作
🟢 完美匹配i智慧 和 591 的社區+價格都一致不用動作
🟡 價格不一致同社區但兩邊價格不同（可能議價過了）修改 591 廣告價
🔴 591 多出591 有上架但 i智慧 沒關注（可能被賣掉了）立刻下架避免被罰
🔵 關注沒對應i智慧 有關注但 591 沒上架確認是否漏上架

❓ 遇到問題

  1. 按鈕沒反應 / 結果頁空白：先確認 i智慧 和 591 都已登入，重新按一次
  2. 結果顯示 0 筆：可能網路慢，按結果頁的「🔄 重新比對」
  3. 更新工具：把新版資料夾覆蓋舊的 → 回到 chrome://extensions/ → 找到擴充功能 → 按右下角「重新整理 🔄」
