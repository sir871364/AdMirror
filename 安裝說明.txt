========================================
 591 × i智慧 比對 —— Network 攔截版 v0.1
 建立日期：2026-08-31
========================================

【這版跟 OCR 版差在哪】

  OCR 版：截圖 → 送本機 PaddleOCR(760MB EXE + 230MB 模型) → 認字 → 解析文字
  這一版：直接讀「i智慧 頁面自己收到的那包 JSON」→ 拿到原始欄位，不用認字

  對 i智慧 的行為完全一樣，都是：
    * 零注入腳本（不用 content script、不用 Runtime.evaluate）
    * 零主動 API 呼叫（不自己發 request，只讀頁面已經收到的 response）
    * manifest 裡沒有 is.ycut.com.tw 的 host_permission

  伺服器端看到的 HTTP 流量與 OCR 版一模一樣（都是真人翻頁觸發的）。
  差別只在「資料怎麼從已載入的頁面取出來」。

  好處：
    - 不用裝 native host、不用 install_host.bat、不用白名單擴充 ID
    - 不用下載 230MB 辨識模型
    - 截圖期間不必「不要動鍵盤滑鼠」
    - 價格 / 坪數 / 樓層是原始數值，不會有 OCR 看錯數字的問題
    - 快很多（省掉截圖與辨識，只剩翻頁時間）
    - i智慧 改版面時不會壞（只有後端 API 欄位改名才會）

----------------------------------------
【安裝】（1 步）
----------------------------------------
1. 開 Chrome → 網址列打 chrome://extensions
2. 右上角「開發人員模式」打開
3. 按「載入未封裝項目」→ 選這個資料夾

  沒有 native host、沒有 EXE、沒有模型要下載。

----------------------------------------
【使用】
----------------------------------------
1. Chrome 先登入 i智慧，也登入 591。
2. 切到 i智慧「關注物件」清單頁（停第幾頁都沒關係）。
3. 按擴充 → 「🚀 自動擷取並比對」。
   - 它會先重新載入該分頁（這是必要的：Network.enable 之前發生的請求拿不到內容）
   - 然後自己翻頁，把每一頁的資料收下來
   - 收滿後自動去抓 591 廣告，比對完開報表新分頁

4. 如果自動翻頁找不到「下一頁 ›」按鈕（版面改了、視窗太窄）：
   改按「🖐 手動擷取（自己翻頁）」→ 自己一頁一頁翻 → 翻完按「✅ 完成擷取」。
   手動模式下每翻一頁畫面上的計數就會增加，看得到進度。

  Chrome 會出現黃色橫幅「⋯正在對這個瀏覽器進行偵錯」，這是 debugger 權限的
  正常提示（OCR 版也有）。不要按「取消」，按了擷取就會中斷。

----------------------------------------
【取得方式：四條路，兩條啟用】（v0.3.0）
----------------------------------------
兩邊各自都有「攔截」和「API」兩套完整實作，目前的組合是：

              攔截            API
  i智慧      ★ 使用中        保留，且無法啟用
  591        保留，可啟用     ★ 使用中

設定在 background.js 最上面：

  const SOURCE_MODE = {
    ismart: 'intercept',   // 'intercept' | 'api'
    s591:   'api'          // 'api' | 'intercept'
  };

刻意不做成 popup 上的勾選框——這兩條路的產出會影響「要不要下架廣告」，
讓使用者隨手切換只會增加誤判的機會。要換就改這裡，然後重新載入擴充。

  ★ 591 改用攔截：把 s591 改成 'intercept' 即可，馬上生效。
    代價是慢（每頁一次完整頁面載入，約 20–40 秒，API 只要 2–4 秒）。
    驗證方式：兩種模式各跑一次，比較報表標頭的「591 廣告 N 筆」，
    數字一樣代表攔截沒有漏頁。

  ★ i智慧 改用 API：改 SOURCE_MODE 還不夠，必須同時在 manifest.json 的
    host_permissions 加入 "https://is.ycut.com.tw/*"，否則 Chrome 會擋下
    executeScript。兩個地方都要改是刻意的設計，避免有人只動一處就
    悄悄啟用了那條「管理員不同意」的路徑。

報表標頭會註明這次兩邊各自是用哪一種模式跑的。

----------------------------------------
【安全防呆】
----------------------------------------
- 若攔截到的筆數少於 i智慧 自己回報的總筆數 90%，直接中止不出報表。
  （漏頁 = 漏掉的物件會被誤判成「591 多出 → 應下架」，代價太高）

- 若這次沒讀到總筆數，報表最上方會顯示橘色警告，提醒你下架前先自己核對筆數。
  這種情況請把 popup 最下方「外層欄位：」那行內容回報給開發者，
  用來把總筆數的欄位名補進 pickTotal()。

【授權鎖 / QR Code / 緊急停止】（v0.4.0 新增）
----------------------------------------
產品代號：listing_compare
  ★ 與 AdMirror 共用同一個代號 —— 本工具是 591 比對工具的新實作，
    不是新產品。後台的授權、試用、到期日、緊急停止都掛在這個代號下。
  ★ 注意：後台停用 listing_compare 會同時停掉 AdMirror 和這一支。
    過渡期兩支併存時無法只停其中一支。
  ★ install_id 是各擴充自己產生的，所以原本 AdMirror 已授權的設備
    裝這一支仍需重新掃 QR 核准一次。

授權流程：
  第一次開擴充若尚未授權，popup 會自動顯示 QR Code。
  請截圖／拍照給管理員，管理員核准並設定到期日後，
  擴充會自己輪詢（每 5 秒），幾秒內解鎖，不用重載。

閘門位置：
  所有檢查都在 background.js（service worker），不在 popup。
  popup 只是顯示層 —— 關掉 popup 或直接對背景發訊息都繞不過去。
  受管制的動作：自動擷取並比對 / 手動擷取 / 只比對。
  （「完成擷取」不設閘門：那只是把已收到的資料收尾，
    中途擋掉只會讓 debugger 卡在附加狀態、資料也白收。
    真正的閘門在後面的比對。）

一律即時向伺服器查詢、不吃本機快取，所以緊急停止是下一個動作就生效。
查不到授權狀態時一律擋下（fail closed）—— 網路不穩會誤擋，
但總比「已經停用了還能跑」好。

【還沒做的】
----------------------------------------
- 加入關注 / 取消關注等寫入操作：這版只做「讀取 + 比對」，不寫入。
- i智慧 物件的「已成交 / 已下架」狀態：
  比對邏輯有支援（w.status），但實測的 66 個欄位裡沒有任何
  statusName / caseStatusName / statusDesc，所以那條規則目前不會生效。
  若 i智慧 的關注清單本來就不會留著已成交物件，這條規則可以直接移除。

【圖示】
----------------------------------------
這支用青綠色，AdMirror 和 OCR 版都是橘色。
三支很可能同時裝在同一個 Chrome，工具列上顏色一樣就分不出誰是誰
（而 AdMirror 會寫入 i智慧 關注、這支只讀不寫，按錯代價不同），
所以刻意做成同造型、不同色。

  icon16/32/48/128.png   目前使用中（青綠 + 訊號徽章）
  icon_alt_admirror.png  AdMirror 原版橘色圖示，備用
  make_icon.py           圖示產生器，改顏色後 python make_icon.py 重跑即可

要改用 AdMirror 那顆：把 manifest.json 的 icons 與 action.default_icon
四個尺寸全部指向 icon_alt_admirror.png，重新載入擴充即可。
